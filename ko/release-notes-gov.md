## Network > VPC > 릴리스 노트

**Network > VPC > 릴리스 노트**

## 2026. 06. 02.

### 기능 개선/변경

* VPC 내부 트래픽 처리 방식 일부 변경
    * 네트워크 서비스 연동 지원을 위해 VPC의 내부 트래픽 처리 방식이 일부 변경되었습니다.
    * 신규 생성되는 VPC부터 적용됩니다.

## 2025. 03. 11.

### 기능 개선/변경

* 라우트 설명 항목 추가
    * 라우트 생성 또는 변경 시 값을 입력할 수 있으며, 라우트 정보에 표시됩니다.
* 라우트의 CIDR, 게이트웨이 항목 변경 기능 추가

## 2024. 09. 05.

### 신규 기능 추가

* Public API에 라우팅 테이블과 연관된 게이트웨이 정보 조회 API 추가
    * [VPC API 가이드](/Network/VPC/ko/public-api/)를 참고하세요.

## 2023. 09. 05.

### 신규 기능 추가

* Public API에 Routing API 추가
    * [VPC API 가이드](/Network/VPC/ko/public-api/)를 참고해 주세요.

## 2023. 04. 04.

### 기능 개선/변경

* Public API에 VPC 및 VPC Subnet API 추가
    * 자세한 사항은 [VPC API 가이드](/Network/VPC/ko/public-api/)를 참고해 주세요.
* API 엔드포인트 주소 변경

## 2022. 04. 05.

### 신규 기능 추가

* 서브넷 정적 라우트 설정 기능 추가
    * 서브넷 내의 인스턴스들에게 DHCP로 전달할 정적 라우트를 설정할 수 있습니다.
* '중앙 집중형 라우팅 테이블' 생성 및 변경 기능 추가

## 2021. 07. 02.

### 기능 개선/변경

* 라우팅 테이블의 기본 라우트(VPC 주소 영역 전체로의 로컬 라우트)가 적용되지 않는 문제 수정
    * 기존에는 VPC 내의 서브넷이라도 같은 라우팅 테이블에 연결되어 있는 서브넷 간에만 통신이 가능했지만, 서로 다른 라우팅 테이블에 연결되어 있는 서브넷 간에도 통신이 가능합니다.

## 2020. 11. 03.

### 기능 개선/변경

* 라우트 생성 창의 게이트웨이 지정 방식 변경
    * 라우팅 테이블의 라우트 생성 창에서 게이트웨이 항목에 IP를 직접 입력하는 방식을 IP를 소유한 장치를 선택하는 방식으로 변경했습니다.
    * 라우팅 테이블에 명시적으로 연결하지 않은 서브넷의 장치도 선택할 수 있습니다.

## 2020. 06. 16.

### 기능 개선/변경

* Public API v2 출시
    * Public API v2는 Openstack API와 호환됩니다.

## 2018. 08. 28.

### 기능 개선/변경

* 서브넷, 라우팅 테이블, 라우트의 최대 생성 가능 개수 조정
    * VPC의 리소스별 최대 생성 가능 개수는 각 리소스 생성 창의 우측 설명 부분에서 확인하실 수 있습니다.
        * 서브넷: VPC당 10개까지 생성이 가능합니다.
        * 라우팅 테이블: VPC당 10개까지 생성이 가능합니다.
        * 라우트: 라우팅 테이블당 10개까지 생성이 가능합니다.

### 버그 수정

* 라우트가 존재하는 서브넷을 가진 VPC의 삭제를 시도할 수 있는 문제 수정

## 2018. 04. 24.

### 기능 개선/변경

* VPC, 서브넷, 라우팅 테이블, 인터넷 게이트웨이 개요 페이지에 연결된 리소스 정보 표시

## 2018. 03. 22.

### 버그 수정

* 새로 추가한 서브넷에 연결한 인스턴스가 DHCP로 IP를 받아오지 못하는 문제 수정
* 라우팅 정책 추가 시 기존 라우팅 정책과 동일한 타깃을 입력할 수 있는 문제 수정
* Floating IP가 연결된 인스턴스에서 다른 서브넷의 인스턴스와 간헐적으로 통신되지 않는 문제 수정

## 2018. 02. 22.

### 기능 개선/변경

* Network 기본 모델로 VPC 도입
    * 서브넷을 여러 개 사용할 수 있습니다.
    * 서브넷 단위로 포트를 생성하여 인스턴스에 연결할 수 있습니다.
    * 라우팅 정책을 추가할 수 있습니다.
    * 인스턴스에 여러 VPC 포트를 추가하거나 삭제할 수 있습니다.
    * 자세한 내용은 VPC Overview와 사용자 가이드를 참고하세요.

### 버그 수정

* Floating IP가 연결된 인스턴스에서 로컬 네트워크로 트래픽이 전달되지 않는 문제 수정
